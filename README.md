# メルカリ助手（Mercari Helper）

メルカリの商品を **メルカリ / Yahoo!フリマ / ヤフオク** にまとめて複製出品し、出品中の商品を一括で再出品・削除できる Tampermonkey スクリプトです。

把煤炉的商品一键复制到 **煤炉 / Yahoo!フリマ / ヤフオク**，并能批量再出品、批量删除的 Tampermonkey 脚本。

---

## インストール / 安装

1. Chrome に拡張機能 **[Tampermonkey](https://chromewebstore.google.com/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo)** を入れる
   在 Chrome 安装 **Tampermonkey** 扩展
2. `chrome://extensions` → Tampermonkey の「詳細」→ **「ユーザースクリプトを許可」をオン**
   打开 `chrome://extensions` → Tampermonkey「详情」→ 打开 **「允许运行用户脚本」**
3. 下のリンクをクリック → 「インストール」
   点下面的链接 → 点「安装」

   **👉 [メルカリ助手をインストール / 安装](https://raw.githubusercontent.com/Bright-ShenJiahao/mercari-helper/main/mercari-helper.user.js)**

4. 初回に「static.mercdn.net へのアクセス」を聞かれたら **「常に許可」**
   第一次运行时如果问是否允许访问 static.mercdn.net，选 **「总是允许」**

更新は自動です（Tampermonkey が定期的に確認します）。
以后会自动更新（Tampermonkey 会定期检查）。

## 使い方 / 用法

### 多平台出品（商品ページ）
商品ページの画像の下にある **「多平台出品」** ボタン →
- 出品先（メルカリ / Yahoo!フリマ / ヤフオク）にチェック、数量・価格を入力
- 番号モード：**加编号**（Z3, Z4…）／**不加编号**（元のタイトルのまま）
- 各行の **「详情」** で、その1件だけの説明（厚さなど）・状態・配送を変更可能
- **试运行**：入力だけして出品しない（各ページで「跳过这件」を押して次へ）
- **开始**：本番出品。Yahoo は「全自动」にチェックすると自動で出品、未チェックなら確認後に手動で出品

商品页图片下方的 **「多平台出品」** 按钮 → 勾选平台、数量、价格；可选加编号/不加编号；每件可点「详情」单独改说明；**试运行**只填不出品；**开始**正式出品。

### 助手面板（出品した商品ページ）
`https://jp.mercari.com/mypage/listings` 左下の **「助手面板」**
- 全商品の取得・絞り込み・並び替え
- 一括再出品（新しく出品して古い方を公開停止）
- 公開停止中の一括削除 / 売却済み（14日経過）の一括削除

「出品した商品」页左下角的 **「助手面板」**：抓取全部商品、筛选排序、批量再出品、批量删除。

## 注意 / 注意事项

- メルカリ・Yahoo に **ログインした Chrome** で使ってください。使用时 Chrome 要先登录煤炉和 Yahoo。
- Yahoo!フリマ・ヤフオクのカテゴリ自動選択は **卓球用品のみ対応**。他カテゴリは手動で選んでください（全自動は半自動に戻ります）。
  Yahoo 两个平台的类别自动选择**目前只对应卓球用品**，其他类别请手动选。
- 実行中はそのウィンドウを最小化しないでください（バックグラウンドだと遅くなります）。
  运行时不要把窗口最小化，放在后台会变慢。
- 各サイトの仕様変更で動かなくなることがあります。**利用は自己責任**でお願いします。
  网站改版可能导致失效，**使用风险自负**。
